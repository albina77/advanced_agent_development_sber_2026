## Текущий результат

M08: 37 из 37 шагов прошли структурные проверки. В первой сессии сумма названа в реплике 2 и использована при подтверждении в репликах 33–34 без повторения клиентом.

| Класс | Состояние |
|---|---|
| F01: вопрос принят за команду | На M08.1.22 проверено capabilities, команда внесения не отправлена |
| F02: потеря номинала | Сохраняется в M01, M02, M05, M06 |
| F03: отрицание изменения предпочтения | На M08.1.25 проверено keep, профиль сохранён |
| D01: неудачный ответ при неполной операции | Сохраняется в M01 после потери номинала |
| T01: зависимые ожидания | Сохраняется: отсутствие эпизода и квитанции после несостоявшейся выдачи нельзя считать самостоятельной ошибкой удаления |

Осталось 12 шагов с FAIL: четыре первичных случая потери номинала и восемь последствий. Успех M08 не доказывает исправление F01/F03 на всех возможных формулировках.
