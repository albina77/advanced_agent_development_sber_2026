# Агент банкомата с памятью и гибридным поиском

Учебный проект по заданию 2 курса «Продвинутая разработка и тестирование ИИ-агентов».

GigaChat извлекает намерения и параметры, LangGraph управляет диалогом. Агент отправляет команды учебному симулятору банкомата, сохраняет предпочтения между сессиями и консультирует по предоставленным документам Сбера.

## Запуск

Нужны Python 3.10+, доступ к сети и собственные ключи GigaChat и Cloud.ru. Скопируйте `atm_agent/.env.example` в `atm_agent/.env` и заполните настройки. Затем из корня репозитория:

```sh
./atm_agent/run.sh --trace
```

Скрипт создаёт виртуальное окружение, устанавливает зависимости, подготавливает недостающий индекс и реранкер, затем запускает диалог. Первый запуск скачивает модель реранкера и расходует токены embeddings API. Готовый индекс используется повторно.

## Проверки

```sh
./atm_agent/run.sh --test -q
./atm_agent/run.sh --synthetic-memory-scenarios
```

В последнем сохранённом живом прогоне 58 из 70 шагов прошли структурные проверки. M08 прошёл все 37 шагов, включая возврат к сумме 12000 ₽ после длинного диалога без повторения суммы клиентом. Остальные известные сбои описаны в отчёте; проект не заявляет прохождение всего набора.

Реальных банковских операций нет. Демонстрационные диалоги вымышлены. Рабочая память, ключи, индивидуальные трассировки, виртуальное окружение и локальные веса моделей исключены из Git.
